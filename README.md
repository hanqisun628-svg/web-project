
# 나만의 캠퍼스 핫스팟

공부하다 잠시 숨을 돌리고 싶을 때 찾아가는 캠퍼스의 세 장소를 소개하는 웹페이지입니다.

## 2주차: 나만의 캠퍼스 핫스팟

### 학교정문
학교에 들어오고 나갈 때 가장 먼저 만나는 장소입니다. 학생들과 교수님들이 이용하는 학교의 주요 출입구를 소개했습니다.

### 식당
학생들과 교수님들이 식사를 하며 휴식을 취할 수 있는 장소입니다. 직접 찍은 사진과 함께 학교 식당을 소개했습니다.

### 운동장
학생들이 운동하거나 산책하면서 휴식을 취할 수 있는 장소입니다. 직접 찍은 운동장 사진과 위치 정보를 추가했습니다.

## 3주차: 네 페이지, 네 가지 분위기

- GitHub Pages URL:https://hanqisun628-svg.github.io/web-project/

### 페이지별 스타일
- 프론트페이지: 세 장소를 한눈에 볼 수 있도록 깔끔하고 단순한 분위기로 구성했습니다. `page-home` 클래스와 흰색 배경, 구분선을 적용했습니다.
- 장소 1: 학교정문은 차분하고 깔끔한 분위기를 표현했습니다. `page-school` 클래스와 파란 계열의 배경 및 테두리를 적용했습니다.
- 장소 2: 식당은 편안하고 따뜻한 분위기를 표현했습니다. `page-restaurant` 클래스와 밝은 배경, 둥근 모서리를 적용했습니다.
- 장소 3: 운동장은 자연스럽고 편안한 분위기를 표현했습니다. `page-playground` 클래스와 초록색 계열의 배경 및 테두리를 적용했습니다.

### 모바일 스타일
- 적용한 @media 조건: `@media (max-width: 600px)`
- 모바일에서 특별히 바뀌는 부분과 이유: 화면이 좁아지면 페이지의 너비와 여백을 줄이고 제목 크기를 작게 변경했습니다. 버튼은 한 줄 전체를 사용하도록 변경하여 휴대전화에서도 쉽게 누를 수 있도록 했습니다.
- 휴대전화에서 네 페이지를 확인한 결과: 작은 화면에서도 내용과 이미지가 화면 안에 맞게 표시되고 링크와 버튼을 쉽게 사용할 수 있도록 구성했습니다.
